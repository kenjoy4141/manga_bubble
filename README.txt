================================================================
  漫画吹き出し自動付与ツール - 使い方
================================================================

【フォルダ構成】
  input/          ... 処理する元画像を置くフォルダ
  output/         ... 吹き出し付き画像の出力先
  input_mosaic/   ... モザイク処理済み画像の出力先
  font/           ... フォントファイル置き場
  bubbles.csv     ... セリフ・位置・色を記述するCSV
  context.txt     ... セリフ自動生成の前提条件（任意）


================================================================
  1. 吹き出しを手動で付ける（add_bubbles.py）
================================================================

【手順】
  1. input/ に画像ファイル（PNG/JPG）を置く
  2. bubbles.csv にセリフを記入する（後述）
  3. 以下を実行:

    python add_bubbles.py

  4. output/ に吹き出し付き画像が保存される


【bubbles.csv の形式】
  列名: filename, day, text1, pos1, color1, text2, pos2, color2, text3, pos3, color3

  - filename : 画像ファイル名（例: s (1).png）
  - day      : 「N日目」表示の番号（空欄なら表示なし）
  - text1〜3 : セリフ（最大3つ）
  - pos1〜3  : 吹き出しの位置（下記の位置名を使用）
  - color1〜3: 吹き出しの色（下記の色名を使用）

【使える位置名】
  top-left    / top-center    / top-right
  center-left / center        / center-right
  bottom-left / bottom-center / bottom-right

【使える色名】
  blue / pink / purple / lavender / green / yellow / red / orange / white / gray

【セリフ記入のコツ】
  - スペース（全角・半角）を入れた位置で改行される
    例: 「もう　やだ　こんなの！」→ 3行に分かれる
  - 1行あたり13〜20字が目安
  - 「…」は自動で「・・・」に変換される


================================================================
  2. セリフを自動生成して吹き出しを付ける（auto_generate.py）
================================================================

【事前準備】
  .env ファイルに API キーを記入:
    ANTHROPIC_API_KEY=sk-ant-...

【手順】
  1. input/ に画像ファイルを置く
  2. （任意）context.txt にキャラクター設定を記入する（後述）
  3. 以下を実行:

    python auto_generate.py

  4. bubbles.csv が自動生成され、続けて吹き出し付き画像も作成される


【context.txt の書き方（任意）】
  キャラクターの名前・性格・口調などを自由に記述する。
  ファイルがない場合はデフォルト設定で生成される。

  記述例:
    登場人物:
    - 眼鏡の女の子（あいり）: 恥ずかしがり屋だが積極的。甘えた口調
    - 男の子（たくや）: やさしい先輩。落ち着いた口調

    注意: あいりのセリフはピンク、たくやはブルーで統一すること


================================================================
  3. センシティブ箇所にモザイクをかける（mosaic.py）
================================================================

【事前準備】
  .env ファイルに API キーを記入（auto_generate.py と共通）

【手順】
  1. input/ に画像ファイルを置く
  2. 以下を実行:

    python mosaic.py              # input/ を処理
    python mosaic.py output       # output/ を処理（吹き出し付き画像に適用する場合）

  3. 入力フォルダ名_mosaic/ にモザイク済み画像が保存される
     例: input/ → input_mosaic/
         output/ → output_mosaic/

【モザイクサイズの自動計算】
  長辺 400px 未満 → 4px固定
  長辺 400px 以上 → 長辺 ÷ 100（例: 1536px → 15px）


================================================================
  4. PNG を JPG に圧縮する（png_to_jpg.py）
================================================================

【実行方法】
  python png_to_jpg.py              # output/ フォルダを品質90で変換
  python png_to_jpg.py input        # input/ フォルダを変換
  python png_to_jpg.py output 85    # 品質85で変換（数値が低いほど圧縮率高め）

  変換後も元の PNG ファイルはそのまま残る。


================================================================
  推奨ワークフロー
================================================================

  【セリフを自分で書く場合】
    1. input/ に画像を置く
    2. bubbles.csv にセリフを記入
    3. python add_bubbles.py
    4. output/ を確認
    5. 必要に応じて python mosaic.py output
    6. python png_to_jpg.py output

  【セリフを自動生成する場合】
    1. input/ に画像を置く
    2. （任意）context.txt にキャラクター設定を記入
    3. python auto_generate.py
    4. output/ を確認、bubbles.csv を手直し
    5. 手直し後は python add_bubbles.py で再生成
    6. 必要に応じて python mosaic.py output
    7. python png_to_jpg.py output
